I attack systems to understand them, then build the detection that catches the same attack. Web and network VAPT on one side, Wazuh rules and SOC automation on the other. Most of what I learn ends up public: write-ups, a SOC lab, and a shelf of tools and hardware builds.

- 🔭 Building **[bugeye](https://github.com/Esther7171/bugeye)**, a browser toolkit for passive recon and web app pentest triage.
- 🛡️ Running a full **[Wazuh SOC lab](https://github.com/Esther7171/Wazuh-SOC-Lab)**: rules, integrations, and automated reporting.
- ✍️ Documenting every box I break in the open. **143+** TryHackMe rooms written up.
- 🎮 Beyond security: FPS games, for the aim and the teamwork.
- 💡 Pro tip: if AI gets you close but not all the way, come ask me.
